# Hands-on DevOps extensions

1. Verify Maven build and test stages.
2. Add JaCoCo coverage and enforce a minimum threshold.
3. Add SpotBugs or Checkstyle.
4. Build Docker image tagged with commit SHA.
5. Scan image using Trivy and publish an SBOM.
6. Push image to a registry using GitHub Actions secrets.
7. Deploy to Kubernetes with config and secret separation.
8. Add Helm/Kustomize overlays for DEV, QA and PROD.
9. Add HPA and load test the API.
10. Add PostgreSQL migrations, Testcontainers and security tests.
